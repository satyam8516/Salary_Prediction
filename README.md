# 💰 Salary Prediction App

A Machine Learning web application built with Streamlit that predicts an employee's salary based on various features such as age, education, experience, job level, department, performance, skills, and more.

## 🚀 Live Demo

https://salaryprediction-bvflxgin96hrsrgfxrdrgs.streamlit.app

## 📌 Features

- Predict employee salary instantly
- Interactive Streamlit interface
- Machine Learning model for prediction
- Encoded categorical features
- Scaled numerical features
- Easy to use and responsive

## 🛠️ Technologies Used

- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy
- Joblib

## 📂 Project Structure

```
Salary-Prediction/
│── app.py
│── salary_model.pkl
│── scaler.pkl
│── encoders.pkl
│── requirements.txt

```

## ▶️ Installation

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
cd YOUR_REPOSITORY
pip install -r requirements.txt
streamlit run app.py
```

## 📊 Input Features

- Age
- Gender
- Education
- Experience Years
- Department
- Job Level
- Performance Rating
- Certifications
- Overtime Hours
- Remote Work
- City
- Company Tenure
- Projects Completed
- Skill Score

## 🎯 Output

The application predicts the estimated employee salary.
